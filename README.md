# HydroRAG

Sistema multiagente basado en RAG para análisis e interpretación de datos hidrogeológicos.

## Arquitectura de almacenamiento vectorial

El proyecto se desarrollará en dos etapas:

- ChromaDB: utilizado como base vectorial para el prototipo inicial y validación del pipeline RAG.
- PostgreSQL + pgvector: utilizado como arquitectura final para una solución escalable e integración con datos hidrogeológicos.

## Tecnologías

- Python
- LangChain
- LangGraph
- PostgreSQL
- pgvector
- ChromaDB
- Streamlit
